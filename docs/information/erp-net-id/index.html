Get to Know ERP.net ID

ERP.net ID gives you one unified global personal account for signing in to supported ERP.net services and maintaining a consistent identity across the ERP.net ecosystem.

Overview

ERP.net ID is your personal global account for signing in to supported ERP.net services.

Instead of creating a separate account for each service, you use one profile to keep a consistent identity across the ERP.net ecosystem.

ERP.net ID accounts are issued and authenticated by ERP.net Identity, which acts as the OpenID Connect identity provider for the ERP.net ecosystem. Applications that support ERP.net ID sign-in redirect users to ERP.net Identity, authenticate them there, and receive standard identity claims (such as the unique user identifier, email, and name) in return.

ERP.net ID helps organizations keep one consistent identity per user across services.

Use ERP.net ID Across Supported Services

You can use ERP.net ID with services that support ERP.net ID authentication.

Supported services include:

  • Operator.net — the AI interface for operating the ERP.net ecosystem through custom-built AI agents and tailored apps.
  • ERP.net Marketplace — the marketplace for apps, packaged solutions, integrations, and services.
  • Marketplace Apps — individual applications delivered through ERP.net Marketplace that accept ERP.net ID as their sign-in method.
  • Vox — the portal for submitting, viewing, and voting on user feature ideas, development suggestions, and business cases.
  • Your ERP.net instance — when ERP.net ID sign-in is enabled on the instance and your instance user's email matches your ERP.net ID email.
  • Other ERP.net services — when they support ERP.net ID authentication.

Understand What ERP.net ID Does

ERP.net ID provides the sign-in identity that supported ERP.net services use to associate your activity with your personal profile.

Each ERP.net ID account holds:

  • Full name — your display name across services.
  • Email address — your sign-in handle and primary contact channel.
  • Password — the credential you use to sign in.
  • Optional profile information — phone number, default language, company, and a registration message.

When you sign in, ERP.net Identity creates an authenticated session and shares your identity claims with the service you're signing in to. The session is managed by ERP.net Identity and the service, not stored as part of the account itself.

Identify the Benefits for Users and Organizations

ERP.net ID is most useful when you work with more than one ERP.net service.

A single personal account helps you move between Operator.net, ERP.net Marketplace, Marketplace Apps, Vox, and enabled ERP.net instances while keeping the same identity and profile details.

For users

ERP.net ID helps you:

  • sign in with one personal account;
  • avoid duplicate or inconsistent accounts;
  • work across services with less account-related friction.

For organizations

When team members register their ERP.net ID with their work email, organizations benefit from:

  • one consistent identity per person across ERP.net services;
  • faster onboarding — a new hire can sign in to every supported ERP.net service from the same account;
  • a single verified email per user for access reviews and support requests.
Note

ERP.net ID is always a personal account. It does not represent organizational membership on its own. Linking users to a specific ERP.net instance, marketplace tenant, or organizational role is handled by each service's own access settings.

Learn How Access Works After Sign-In

After sign-in, each service uses your ERP.net ID profile according to its own access settings, enabled features, and permission rules.

This allows one ERP.net ID account to work across multiple services, while each service or ERP.net instance still controls its own access rules.

Access can depend on:

  • whether the service supports ERP.net ID authentication;
  • whether your ERP.net ID account is active;
  • whether ERP.net ID sign-in is enabled on the ERP.net instance you're trying to access;
  • your assigned permissions;
  • administrator approval, where required.
Note

ERP.net ID supports sign-in and identification. Service access and ERP.net instance permissions are managed according to the relevant service, organization, and administrator settings.

Summary and Additional Resources

ERP.net ID helps you sign in to supported ERP.net services with one global personal account. It is especially useful when you work across multiple ERP.net entry points.
